# 포켓몬 강화하기 🔨⚡

검강화하기 스타일을 포켓몬으로 옮긴 단일파일 클릭커 게임. 외부 의존성 없음. **모바일 완전 대응.**

- 🎮 플레이: https://mgmudkip.github.io/pokemon-enhance/
- 📦 리포: https://github.com/MgMudkip/pokemon-enhance

## 실행

```bash
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

파일을 직접 더블클릭해도 동작한다.

## 룰 (검강화 그대로)

- `+0 ~ +30` 강화, 성공 확률은 고강으로 갈수록 하락 (100% → 1%)
- 강화 비용은 기하급수적으로 상승, 판매가는 더 가파르게 상승 (도박 구조)
- 실패 시:
  - `0~5강`: 유지
  - `6~10강`: -1
  - `11~15강`: -2
  - `16강~`: -3 + **파괴(→0강)** 확률 (16강 2% → 29강 30%)
- 연속 실패 시 자비 보너스 +2%/회 (최대 +10%)
- 골드 부족 소프트락 없음: `⚔️ 사냥하기`로 항상 파밍 가능 (10% 확률 3배 대박)

## 진화 시스템 ✨

- `+0~6`: 1단계 → **`+7`에서 1차 진화** → **`+16`에서 최종 진화**
- 진화 연출(플래시 + 전용 징글 + 폭죽), 진화 시 CP 배율 ×1 → ×1.6 → ×2.5, 판매가 ×1 → ×1.3 → ×1.8
- 강화 하락·파괴로 진화선 밑으로 떨어지면 **퇴화**
- 📖 진화 도감 18종(6라인 × 3단계) 수집 — 미발견은 실루엣 표시

## 포켓몬 6종 (인라인 SVG 오리지널 아트)

| 라인 | 1단계 → 2단계 → 최종 | 특성 |
|---|---|---|
| 전기쥐 | 피츄 → 피카츄 → 라이츄 | 밸런스 |
| 화염도롱뇽 | 파이리 → 리자드 → 리자몽 | 판매↑ 확률↓ |
| 물거북 | 꼬부기 → 어니부기 → 거북왕 | 확률 +5% |
| 씨앗개구리 | 이상해씨 → 이상해풀 → 이상해꽃 | 확률 +8% 안정형 |
| 진화여우 | 이브이 → 샤미드 → 님피아 | 저렴 · 초보추천 |
| 환생에스퍼 | 뮤 → 뮤츠 → 메가뮤츠 | 판매 2배 · 확률 -10% 도박형 |

랭크: 노말 → 그레이트(5) → 울트라(10) → 마스터(15) → 하이퍼(20) → 챔피언(25) → 👑아르세우스급(30)

## 조작

- 모바일: 큰 버튼 터치 (강화/사냥/판매), 진동 + 사운드, 더블탭 줌 방지
- PC: `Space`=강화, `H`=사냥, `S`=판매
- 🤖 자동강화 토글, 📖 포켓몬 변경, ↻ 초기화, localStorage 자동저장
