# 포켓몬 강화하기 🔨⚡

검강화하기 스타일을 포켓몬으로 옮긴 단일파일 클릭커 게임. **모바일 완전 대응.**

> 이미지: PokeAPI 공식 아트워크 사용 (©Nintendo/Creatures Inc./GAME FREAK, 팬 메이드).
> 나무위키는 핫링크를 차단해서 직접 쓸 수 없어, 같은 공식 아트워크를 안정적으로 제공하는 PokeAPI로 연결했다.

- 🎮 플레이: https://mgmudkip.github.io/pokemon-enhance/
- 📦 리포: https://github.com/MgMudkip/pokemon-enhance

## 실행

```bash
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

파일을 직접 더블클릭해도 동작한다.

## 룰 (검강화 그대로)

- `+0 ~ +30` 강화, 성공 확률은 고강으로 갈수록 하락 (100% → 1%)
- 강화 비용은 기하급수적으로 상승, 판매가는 더 가파르게 상승 (도박 구조)
- 실패 시:
  - `0~5강`: 유지
  - `6~10강`: -1
  - `11~15강`: -2
  - `16강~`: -3 + **파괴(→0강)** 확률 (16강 2% → 29강 30%)
- 연속 실패 시 자비 보너스 +2%/회 (최대 +10%)
- 골드 부족 소프트락 없음: `⚔️ 사냥하기`로 항상 파밍 가능 (10% 확률 3배 대박)

## 진화 시스템 ✨

- `+0~6`: 1단계 → **`+7`에서 1차 진화** → **`+16`에서 최종 진화**
- 진화 연출(플래시 + 전용 징글 + 폭죽), 진화 시 CP 배율 ×1 → ×1.6 → ×2.5, 판매가 ×1 → ×1.3 → ×1.8
- 강화 하락·파괴로 진화선 밑으로 떨어지면 **퇴화**
- 📖 진화 도감 24종(8라인 × 3단계) 수집 — 미발견은 실루엣 표시

## 포켓몬 8종 (PokeAPI 공식 아트워크)

| 라인 | 1단계 → 2단계 → 최종 | 특성 | 해금 |
|---|---|---|---|
| 전기쥐 | 피츄 → 피카츄 → 라이츄 | 밸런스 | 처음부터 |
| 진화여우 | 이브이 → 샤미드 → 님피아 | 저렴 · 초보추천 | 처음부터 |
| 화염도롱뇽 | 파이리 → 리자드 → 리자몽 | 판매↑ 확률↓ | 배틀 3승 |
| 물거북 | 꼬부기 → 어니부기 → 거북왕 | 확률 +5% | 배틀 6승 |
| 씨앗개구리 | 이상해씨 → 이상해풀 → 이상해꽃 | 확률 +8% 안정형 | 배틀 10승 |
| 환생에스퍼 | 뮤 → 뮤츠 → 메가뮤츠Y | 판매 2배 · 확률 -10% 도박형 | 배틀 15승 |
| 해왕 | 가이오가 → 가이오가 → 원시가이오가 | 전설 · 판매 3배 | 🌊 가이오가 레이드(+12) 처치 |
| 대륙왕 | 그란돈 → 그란돈 → 원시그란돈 | 전설 · 판매 3배 | 🌋 그란돈 레이드(+16) 처치 |
| 시간신 | 디아루가 → 디아루가 → 오리진디아루가 | 전설 · 판매 3배 | 🔷 금강옥 구매(5만G) |
| 공간신 | 펄기아 → 펄기아 → 오리진펄기아 | 전설 · 판매 3배 | 💠 백옥 구매(5만G) |

## 자동 골드 💰

- 초당 자동 수급: `3 + 레벨×1.5 + 도감×1.5 + 해금×3 + 승리×0.5`G/s, 가만히 둬도 쌓임
- 오프라인 보상: 종료 후 최대 8시간까지 50% 적립, 복귀 시 팡파레와 함께 지급

## 배틀 아레나 🔥

- 야생 배틀: 비슷한 레벨의 야생 포켓몬과 턴제 승부. 공격 연타 + 12초 쿨 Z기술(2.6배)
- 상성표: 불〉풀〉물〉불, 전기〉물〉땅〉전기, 땅〉불, 에스퍼·노말은 무난. 유리하면 2배!
- 레이드: +12 🌊가이오가 처치 시 해금(8000G) · +16 🌋그란돈 처치 시 해금(15000G), 이후 재도전 가능
- 승리할수록 도감이 열린다: 3승 파이리 → 6승 꼬부기 → 10승 이상해씨 → 15승 뮤

## 재미 요소 🎰

- 🔥 **FEVER 타임**: 강화할 때마다 7% 확률로 15초간 성공 +12%·사냥 ×2·크리율 2배
- 💥 **크리티컬**: 성공의 12% 확률로 +2 점프 (FEVER 중 24%)
- ✦ **이로치**: 강화 성공의 3% + 레이드 승리 시 10% 확률. 전설 포함 전부 가능, 판매가 2.5배
- 🔗 **콤보**: 연속 성공마다 성공률 +1% (최대 +10%), 판매가도 콤보 비례 상승. 하락·파괴 시 리셋
- 🛍 **상점**: 🛡 파괴 방어막 · 🍀 행운의 부적 · 🧲 골드 자석 · 🔷 금강옥(디아루가 해금) · 💠 백옥(펄기아 해금)
- 🏆 **업적 18종**: 첫 진화·콤보 10·이로치·도감 완성·첫 승리·전설 처치·옥 구매 등, 달성 즉시 골드 자동 지급
- 🎵 **BGM**: 유튜브 음악 자동 재생(첫 터치 후), 🎵 버튼 ON/OFF. 상성표에 강철 추가(강철〉전기·에스퍼, 불·땅〉강철)

랭크: 노말 → 그레이트(5) → 울트라(10) → 마스터(15) → 하이퍼(20) → 챔피언(25) → 👑아르세우스급(30)

## 조작

- 모바일: 큰 버튼 터치 (강화/사냥/배틀/판매), 진동 + 사운드, 더블탭 줌 방지
- PC: `Space`=강화, `H`=사냥, `S`=판매, `B`=배틀
- 🤖 자동강화 토글, 📖 포켓몬 변경, ↻ 초기화, localStorage 자동저장
